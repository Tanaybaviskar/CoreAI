### 2. Weather API (FREE, 1M calls/month)

**OpenWeatherMap (Recommended)**
- **Cost:** $0
- **Credit Card:** Not needed
- **Limits:** 60 calls/min, 1,000,000/month
- **Setup:** 5 minutes

**Steps:**
1. Go to https://openweathermap.org/api
2. Click "Sign up" (just email, no payment)
3. Go to API Keys section
4. Copy your key
5. Add to `.env`:
   ```env
   WEATHER_API_KEY=your_key_here
   WEATHER_API_PROVIDER=openweathermap
   ```

### 3. News API (FREE, 100 calls/day)

**Cost:** $0 | **Credit Card:** Not needed | **Limits:** 100/day

**Steps:**
1. Go to https://newsapi.org/
2. Get API Key (choose "Developer" plan - it's FREE)
3. Activate via email
4. Add to `.env`:
   ```env
   NEWS_API_KEY=your_key_here
   ```
